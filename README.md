## How to Use

In your terminal, run the following command:

```bash
git clone https://github.com/gloxadacademy/ng_frontend.git
```
```bash
cd ng_frontend
```
```bash
npm i
```

## Running Tests

```bash
npm run test
```

## Running Dev Server

```bash
npm run dev
```
